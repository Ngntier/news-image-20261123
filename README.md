A dense newspaper front page summing up the world's news of Monday
23 November 2026: 28 sourced stories, two lead stories (Nvidia reinstates
Jensen Huang; Ukraine sinks a Russian ship off Libya), a markets strip and
a UTC timeline. Drawn in pure standard-library Python — no photos, no
network — so the program runs anywhere and writes byte-identical output
every time. See `NEWS.md` for the story list with sources.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `entry.png` (1024x1024, under 1 MiB).
